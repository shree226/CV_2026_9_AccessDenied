# Multimodal MRI and Genetic Fusion for Alzheimer's Disease

A collaborative Computer Vision project conducted as part of **CSE641 at Ahmedabad University**, under the guidance of **Dr. Mehul Raval**.

This project investigates the relationship between genetic susceptibility and structural brain changes in Alzheimer's disease using longitudinal MRI and genetic data from the **Alzheimer's Disease Neuroimaging Initiative (ADNI-2 and ADNI-3)**. The proposed pipeline combines HD-BET and FastSurfer for MRI preprocessing and anatomical segmentation, MedicalNet (3D ResNet-18) for deep feature extraction, and genetic features including APOE encoding and principal components. These multimodal representations are used to explore clinical cognitive score prediction and longitudinal progression modeling.

Clinical regression using Optuna-optimized XGBoost achieved a reported cross-validated \(R^2\) of **0.519** and MAE of **1.83**, while temporal regression experiments explored longitudinal changes in hippocampal volume and MRI-derived features. The project was collaboratively developed by **Dhriti Gandhi, Devashree Parikh, Yash Shah and Ura Modi**.
